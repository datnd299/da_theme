# 1. DESIGN NORTH STAR

Clixframe should feel like a digital growth company operating at the intersection of:

**CREATIVE × MEDIA × DATA × OPERATIONS**

The website should NOT immediately feel like a traditional marketing agency.

The first impression should feel closer to:

* a performance technology company
* a modern growth platform
* a digital operating system
* a high-performance creative business

The experience should communicate:

**SPEED
SIGNAL
MOMENTUM
PRECISION
GROWTH**

---

# 2. CORE DESIGN IDEA

## THE GROWTH SIGNAL

The visual identity is based around one idea:

Every digital interaction creates a signal.

A click is a signal.
A view is a signal.
A lead is a signal.
A conversion is a signal.
A customer is a signal.

Clixframe connects these signals and turns them into growth.

This idea should influence:

* motion
* interface graphics
* charts
* cards
* backgrounds
* transitions
* icons
* data visualization

Visual language:

**SIGNAL → CONNECTION → MOVEMENT → GROWTH**

**Motion should communicate performance, not decorate the page.**

# 35. MOTION SPEED

Micro interactions:

150–250ms

UI transitions:

300–500ms

Large reveal:

600–900ms

Ambient animations:

4–12 seconds

Avoid excessive slow cinematic animations that make the site feel heavy.

Clixframe should feel FAST.

---

# 36. SCROLL MOTION

Use:

fade + translate
masked text reveals
graph drawing
number counting
signal movement
card stacking
horizontal data movement

Avoid making every section scroll-jacked.

Native scrolling should remain smooth and predictable.

# 59. ACCESSIBILITY

Maintain readable contrast.

Do not use Signal Lime for long text.

Do not communicate performance using color alone.

Respect:

`prefers-reduced-motion`

Animations must degrade gracefully.

Keyboard navigation must remain visible.

---

# 60. PERFORMANCE

High-tech does not mean heavy.

Avoid:

huge background videos
multiple WebGL scenes
unoptimized 3D
unnecessary JavaScript animation

Prefer:

CSS transforms
SVG
Canvas only where useful
optimized video
lazy loading

Target:

fast initial render.

Hero should become understandable before all animations load.
