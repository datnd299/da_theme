# Bardic — Design System

# Design Philosophy

## Core Principle

Bardic should feel like a premium handcrafted artisan experience.

The interface must communicate:

* craftsmanship
* calmness
* timelessness
* emotional warmth
* authenticity
* tactile beauty

The website should never feel:

* loud
* overly commercial
* generic ecommerce
* dropship-oriented
* cluttered

The visual language should feel like:
"A modern artisan workshop inspired by ancient music and storytelling."

---

# Design Keywords

## Brand Keywords

* cinematic
* handcrafted
* soulful
* earthy
* immersive
* artistic
* premium
* tactile
* quiet luxury
* intentional

---

# Core UX Principles

## 1. Emotional Before Functional

Users should emotionally connect before evaluating product details.

The interface should prioritize:

* atmosphere
* storytelling
* texture
* immersion

before:

* specifications
* technical details
* ecommerce mechanics

---

## 2. Calm Visual Rhythm

The site should encourage slow scrolling and emotional absorption.

Avoid:

* information overload
* visual chaos
* aggressive promotions
* excessive animation

---

## 3. One Dominant Focus Per Viewport

Each section should contain:

* one primary message
  OR
* one primary visual focus

Avoid competing visual priorities.

---

## 4. Whitespace Creates Value

Generous spacing increases:

* perceived luxury
* readability
* emotional pacing
* trust

Spacing is part of the brand identity.

# Color Usage Rules

## Backgrounds

Primary backgrounds should use warm light tones.

Avoid:

* pure white
* harsh black
* heavy gradients

---

## Accent Colors

Accent colors should be used sparingly.

Primary accent:

* Antique Gold

Use for:

* buttons
* links
* hover emphasis
* small highlights

---

## Text Contrast

Text should feel soft but readable.

Use:

* walnut brown instead of black
* warm neutrals instead of gray
