# luxurytheme.com — HOME PLAN

## 1. Homepage Goal

Homepage là trang định hình toàn bộ phong cách website.

Mục tiêu chính:

* Tạo ấn tượng luxury ngay khi truy cập
* Giới thiệu thương hiệu và collection
* Làm nổi bật sản phẩm
* Tăng product discovery
* Xây dựng trust
* Dẫn người dùng đến purchase

Overall feeling:

**Modern + Quiet Luxury + Editorial + Product Focused**

---

## 3. Header

### Desktop

Header cao khoảng:

```text
80px
```

Layout:

```text
Logo

Watches
Collections
New Arrivals
Discover
Services

Search
Account
Wishlist
Cart
```

Header mặc định transparent nếu nằm trên hero.

Khi scroll:

```text
Background: Ivory / White
Text: Black
Thin bottom border
```

Transition nhẹ khoảng `300ms`.

---

## 4. Hero Section

Hero là phần quan trọng nhất của homepage.

### Layout

Full-width cinematic image hoặc video.

```text
Height: 85–100vh
```

Content nên nằm bên trái hoặc center-left.

Ví dụ:

```text
NEW COLLECTION

THE ART OF TIME

Precision shaped by craftsmanship.

[DISCOVER COLLECTION]
```

Không dùng quá nhiều text.

### Hero Visual

Ưu tiên:

* Wrist shot cao cấp
* Macro watch detail
* Dark cinematic environment
* Luxury architectural background

Text phải luôn dễ đọc.

---

## 5. Featured Collection

Ngay sau hero nên giới thiệu collection chính.

Layout desktop:

```text
50% Image
50% Content
```

Có thể đảo layout giữa các section.

Content:

```text
Collection Name

Short editorial description.

[EXPLORE COLLECTION]
```

Image tỷ lệ:

```text
3:4 hoặc 4:5
```

Section spacing lớn để tạo cảm giác premium.

## 18. Homepage Motion

Allowed animations:

```text
Fade up
Image reveal
Slow zoom
Product hover
Text reveal
```

Motion should remain subtle.

Typical duration:

```text
300–700ms
```

Avoid:

* Bounce
* Fast parallax
* Excessive scrolling effects
* Constant movement

---

## 19. Mobile Homepage

Mobile order should remain:

```text
Hero
Featured Collection
Featured Watches
Brand Story
New Arrivals
Craftsmanship
Signature Collection
Services
Journal
Newsletter
Footer
```

Important mobile rules:

* Reduce long text
* Use swipe product sections
* Keep CTA visible
* Large tap targets
* Large watch images
* Reduce heavy animation
* Maintain generous spacing

---

## 20. Homepage UX Rules

Every section should have one clear purpose.

Avoid multiple CTAs competing in the same section.

Preferred:

```text
1 Main Message
1 Supporting Message
1 Primary CTA
```

User should always understand what to explore next.

## 23. Homepage Visual Rules

DO:

* Use large photography
* Keep generous whitespace
* Let products dominate
* Use dark/light section rhythm
* Keep copy concise
* Use subtle animation

DON'T:

* Add too many banners
* Use aggressive promotions
* Add excessive gold
* Fill empty spaces
* Use heavy shadows
* Create too many different card styles
