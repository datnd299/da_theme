# House of Shoes Online — Design System V2

## Design Goal

Build a modern feminine footwear ecommerce website inspired by the original House of Shoes / Vegas House of Shoes identity.

The old brand used strong pink, black shoe silhouettes, feminine styling, and a bold Vegas boutique feel. The new website should keep that recognizable pink/purple energy, but make it cleaner, more modern, more premium, and more suitable for GMC approval.

The site should feel:

* Feminine
* Bold
* Modern
* Stylish
* Confident
* Pink-forward
* Shoe-focused
* Boutique-like
* Easy to shop
* GMC-safe

The website should not feel like:

* An outdated Facebook flyer
* A nightclub/adult-style promo page
* A fake branded sneaker shop
* A luxury replica store
* A random fashion marketplace
* A medical orthopedic claim site

---

## Core Visual Direction

```txt
Modern Pink Footwear Boutique
```

The design should combine:

* hot pink brand energy
* soft purple/lavender backgrounds
* clean white ecommerce cards
* black/charcoal contrast
* feminine footwear photography
* confident shoe boutique styling
* modern product-first layouts

The website should feel more polished than the old Facebook page, while still clearly remembering its brand DNA.

## Typography Rules

* Headings: bold, modern, feminine, confident
* Body: clean, simple, readable
* Product titles: direct and easy to scan
* Buttons: short and clear
* Avoid overly decorative script fonts
* Avoid old 2000s bubbly display fonts from the Facebook banner

Suggested sizing:

```txt
H1 desktop: 48–64px
H2 desktop: 32–44px
Body: 16–18px
Product title: 15–17px
Button: 14–16px, medium-bold
```

# Layout Style

Use a clean boutique ecommerce layout:

* Large hero with pink/purple accent
* White product cards
* Image-heavy category cards
* Modern footwear feature sections
* Dedicated size/fit trust block
* Dark boutique footer/trust section
* Mobile-first spacing

Recommended width:

```txt
max-w-7xl
```

Recommended spacing:

```txt
Desktop: py-20 / py-24
Mobile: py-14 / py-16
```

Border radius:

```txt
Cards: 20–28px
Buttons: 999px or 14px
Images: 22–32px
```

# Image Direction

Use realistic footwear imagery with a modern boutique feel:

* Statement heels on clean studio background
* Women’s shoes in stylish lifestyle scenes
* Close-up heel details
* Sneakers on clean neutral surfaces
* Sandals/slides in casual settings
* Slippers in cozy home scenes
* Boots in seasonal lifestyle scenes
* Shoe packaging and boutique display

Image rules:

* No fake major brand logos
* No text inside product images
* No supplier collage images
* No medical foot before/after visuals
* No counterfeit-looking shoe designs
* Avoid overly sexual nightlife visuals
* Shoes must be clearly visible
* Use pink/purple accent props where helpful

---

# Product Card Style

Product cards should feel modern and boutique-like:

* Clean White background
* Rounded corners 20–28px
* Soft border or light shadow
* Large shoe image
* Product title
* Price
* Size availability note if useful
* Simple CTA

Optional badges:

```txt
New
Boutique Pick
Comfort Style
Statement Style
```

Badge colors:

```txt
New: House Pink
Boutique Pick: Violet Glow
Comfort Style: Rose Beige with dark text
Statement Style: Soft Fuchsia
```

Avoid:

* Too many sale badges
* Fake reviews
* Countdown timers
* Fake brand labels
* Keyword-stuffed product names

# Trust Elements

Always include:

* Secure checkout
* Tracking included
* 30-day returns
* Support email
* Shipping timeline
* Size guide
* Fit notes
* Product material details
* Footwear return condition

Important fit note:

```txt
Please review the size guide, fit note, material details, and return conditions before placing an order.
```

Trust section style:

* Dark Boutique Gradient background
* White text
* House Pink / Violet Glow accents
* Clean trust cards
* Size Guide CTA clearly visible

---

# Product Page Requirements

Every footwear product page should include:

```txt
Shoe type
Gender / target use if relevant
Available sizes
Color options
Material / upper / sole / heel height if known
Fit note
Care instructions
Shipping note
Return condition
Size guide link
```

For heels, include heel height when available.

Avoid product pages that only show image and price.

# GMC-Safe Rules

Do not use:

* Fake Nike / Adidas / Crocs / Birkenstock claims
* Replica / dupe wording
* Unauthorized brand logos
* Medical orthopedic claims unless verified
* Guaranteed pain relief claims
* Fake reviews
* Countdown timers
* Misleading official brand affiliation
* Overly adult nightlife imagery

Safe wording:

```txt
everyday shoes
statement heels
women’s shoes
comfort
casual style
daily wear
confident steps
easy movement
sneakers
sandals
slides
slippers
boots
size guide
fit note
```

# Final Design Feeling

House of Shoes Online should look like:

> A modern pink footwear boutique offering women’s shoes, statement heels, sneakers, comfort shoes, sandals, slides, slippers, boots, and everyday footwear for confident steps.

The website must feel shoe-focused, feminine, bold, modern, stylish, trustworthy, and GMC-safe — while still preserving the pink/purple House of Shoes identity from the original Facebook presence.
