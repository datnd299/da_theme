# Broge Shoes — Home Plan

## Homepage Goal

Build a luxury-inspired men’s formal footwear homepage for only three categories:

```txt
Formal Shoes
Leather Dress Shoes
Brogue Shoes
```

The homepage must feel:

* Luxury
* Masculine
* Polished
* Formal
* Professional
* Easy to understand
* GMC-safe

Main homepage message:

```txt
Modern Formal Shoes For Classy Steps
```

The homepage should clearly show that Broge Shoes is a focused men’s dress footwear store, not a sneaker store, random shoe marketplace, or fake luxury brand.

---

# Homepage Structure

Use 6 sections maximum:

```txt
1. Hero
2. Shop By Style
3. Formal Shoes For Work & Events
4. Leather Dress Shoes & Brogue Details
5. Customer Care / Size & Returns Trust
6. Customer Feedback
```

The final section must be **Customer Feedback**.

End the homepage with trust and social proof while staying GMC-safe.
