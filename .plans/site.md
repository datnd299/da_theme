## Return & Refund Policy Direction

Return & Refund Policy must follow the Crowdfused-style return structure used in the previous projects.

Required sections:

1. Hero
2. 30-Day Easy Returns
3. $0 Restocking Fee
4. Return Policy Overview
5. Return Costs
6. Common Return Scenarios
7. How To Return An Item
8. Return Authorization Required
9. Refund Process
10. Exchanges
11. Non-Returnable Items
12. Questions
13. Contact Information

Default return parameters:

* **Return window:** 30 days from delivery
* **Restocking fee:** $0 for eligible returns
* **Condition:** Items must be unused, unworn, undamaged, in original condition, and returned with original packaging where applicable
* **Return authorization:** Required before sending items back
* **Defective / incorrect / damaged products:** Store covers return shipping or provides a prepaid label after approval
* **Customer remorse / wrong size / wrong color / wrong model / preference change:** Customer pays actual return shipping cost
* **Original shipping costs:** Non-refundable unless the return is due to store error or carrier/product damage
* **Refund timing:** Refunds are processed to the original payment method after inspection and approval, typically up to 7 days depending on bank or payment provider
* **Exchanges:** Subject to stock availability

Footwear-specific return note:

> Eligible footwear must be unworn, undamaged, free of outdoor wear, stains, heavy creasing, odor, or sole marks, and returned with original packaging where applicable.

Custom footwear return note:

> Custom, personalized, made-to-order, or modified footwear may be non-returnable unless defective, damaged, incorrect, or required by applicable law. This must be clearly stated on relevant product pages.
