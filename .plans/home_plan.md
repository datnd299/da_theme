# Handed Shoes — Home Plan

## Homepage Goal

Build a professional, refined men’s formal footwear homepage for:

```txt
Oxford Shoes
Brogue Shoes
Loafers
Monk Strap Shoes
```

Main homepage message:

```txt
Crafted-Look Dress Shoes For Polished Steps
```

The homepage should feel:

```txt
masculine
craft-inspired
formal
polished
professional
trustworthy
GMC-safe
```

The homepage must stay focused on men’s dress footwear and should not feel like a sneaker store, streetwear shop, fake luxury store, or random footwear marketplace.

---

# Homepage Structure

Use 6 sections maximum:

```txt
1. Hero
2. Shop By Style
3. Oxford Shoes For Work & Formal Style
4. Brogues, Loafers & Monk Strap Details
5. Customer Care / Size & Returns Trust
6. Customer Feedback
```


